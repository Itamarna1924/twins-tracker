# יומן התאומים

אפליקציית מעקב לתאומים (PWA): האכלה, שעוני הנקה, חיתולים, שינה, בריאות, עקומות גדילה, מזון מוצק, חלב, מלאי והורים.

- **אפליקציה:** קבצים סטטיים שמוגשים מ־GitHub Pages. נתונים, כניסה והתראות דרך Firebase.
- **תזכורות:** `.github/workflows/reminders.yml` רץ כל 10 דקות ושולח התראות פוש (`notifier/`).
- **הרשאות:** כללי האבטחה של Firestore מוגדרים במסוף של Firebase (תבנית ב־`firestore.rules.template`). מי מורשה להיכנס נשמר במסד הנתונים, לא בקוד.

הקוד לא מכיל נתונים אישיים. הגדרות Firebase שב־`config.js` ציבוריות מטבען.
